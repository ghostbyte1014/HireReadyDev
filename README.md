# HireReady Dev — The Developer's IT Compendium

![HireReady Dev Hero Banner](./public/hero-banner.jpg)

**HireReady Dev** is an offline-first Progressive Web Application (PWA) designed as a comprehensive field guide, developer toolchain reference, and technical job interview masterclass for software engineers, IT professionals, and students.

---

## ✨ Features

- **📚 16 Core IT Domains (80+ Topics)**: From programming fundamentals, data structures, algorithms, databases, web development, and networking to DevOps, cloud system design, security, and AI agentic systems.
- **🎯 13 Interview Categories (70+ Q&As)**: Detailed technical and HR interview questions with sample answers, HR evaluation criteria, and key remember notes.
- **⏱️ Interactive Practice Mode**: Active recall testing with hidden answers, a 60-second practice timer, and progress tracking (`✓ Mastered`, `Review Needed`).
- **🌱 Starter & 🔬 Deeper Views**: Switch between 30-second quick skim summaries and deep architectural tradeoffs/edge cases.
- **🌐 300+ Verified Free Documentation Links**: Hand-curated links to official documentation (MDN, W3C, RFCs, Python, Docker, PostgreSQL) with offline Wi-Fi connection interceptor.
- **⚡ 100% Offline-First PWA**: Built with Vite and PWA Service Workers so you can study anywhere without Wi-Fi.

---

## 🚀 Quick Start

### 1. Installation

```bash
git clone https://github.com/ghostbyte1014/HireReadyDev.git
cd HireReadyDev
npm install
```

### 2. Development Server

```bash
npm run dev
```

Open `http://localhost:3000` in your browser.

### 3. Production Build

```bash
npm run build
```

## 🛠️ Tech Stack

- **Framework**: React 18
- **Build Tool**: Vite 5
- **Icons**: Lucide React
- **PWA**: Service Workers & Web App Manifest
- **Styling**: Vanilla CSS with curated color system
